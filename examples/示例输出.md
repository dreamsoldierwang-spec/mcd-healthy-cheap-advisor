# 示例输出 · 一次完整调用（mock 数据，仅演示）

> **数据为演示用 mock，非真实优惠 / 价格。**

## 用户输入
> 今天午餐怎么吃得健康又便宜？热量目标 600 kcal，预算 30 元，不要油炸。

## Skill 取数（MCP 真实返回示意）
- `list-nutrition-foods` → 8 个餐品（含能量/蛋白/脂肪/碳水/钠/价格）
- `campaign-calendar` → 当月 3 个活动，其中 2 个「进行中」
- `available-coupons` → 4 张可领券（满30减12 / 买一赠一 / 5折 / 满20减6）

## 分析过程（节选）
- 忌口过滤：剔除名称含「炸」的餐品（本例无命中）。
- 组合生成：单品 8 + 双拼 28 = 36 个候选，热量 ≤ 660 kcal 的保留 22 个。
- 优惠匹配：双拼「板烧鸡腿堡 + 玉米杯」原价 ¥30，套「满30减12」→ 到手 ¥18，省 ¥12。
- 综合评分：营养分×0.5 + 热量适配×0.3 + 省钱分×0.2，取 Top 3。
