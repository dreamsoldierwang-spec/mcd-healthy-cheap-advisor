## 配色参考（设计用，非品牌规范）

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 主红 | `#DA291C` | 标题、强调、按钮 |
| 主黄 | `#FFC72C` | 高亮、标签底、点缀 |
| 深灰文字 | `#27251F` | 正文 |
| 浅灰底 | `#F7F4EF` | 卡片背景 |
| 白色 | `#FFFFFF` | 主背景 |
| 健康绿 | `#2E7D32` | 营养/低卡正向提示 |
| 省钱蓝 | `#1565C0` | 价格/优惠提示 |

> 配色取自麦当劳公开视觉印象；本 Skill 额外引入「健康绿 / 省钱蓝」双语义色，让「健康 vs 便宜」一眼可分。

## 字体建议
- 中文正文：系统默认无衬线（PingFang SC / Microsoft YaHei）。
- 数字 / 标题：适度加粗，利益点（省 X 元、X kcal）放大呈现。

## 风格基调
- **生活感、克制、不模板化**：少堆卡片，多用真实数据呈现。
- **双语义可视化**：绿色表健康（低卡/高蛋白），蓝色表便宜（到手价/省多少）。
- **口语化**：像朋友支招，不像广告通稿。

## 图标 / 插画
- 优先用 emoji（🥗💰🔥🍔）做轻量视觉，避免绘制官方吉祥物。
- 如需插画，采用扁平、原创、抽象风格，不与官方 IP 雷同。
