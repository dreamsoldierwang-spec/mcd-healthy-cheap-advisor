> 本文件定义「今日餐盘」的 Markdown 输出格式。Skill 在 Step 4 套用。
> 所有数字来自 MCP 真实返回；缺数据处标注「以门店/活动页实际为准」。

---

```markdown
🎯 点评：高蛋白低卡，正好卡在午餐 600 kcal 目标内；叠周一会员日更香。
━━━━━━━━━━━━━━━━

🍽 今日餐盘推荐（第 2 套 · 最省钱）
...

...
```

## 二、字段填法

| 字段 | 取值 |
| --- | --- |
| 餐品组合 | 组合内餐品名，` + ` 连接 |
| 总热量 / 蛋白 / 脂肪 / 碳水 | 组合累加，保留 1 位小数 |
| 原价 | 有单价时填；无单价时整段改为「💰 省钱提示：可叠加 X 券（减Y/折扣），具体以结算页为准」 |
| 可用券 | 券名 + 门槛/优惠摘要 |
| 到手价 / 省多少 | 有单价时算；无单价时省略，改提示 |
| 点评 | 取自 analysis-playbook 的解释模板，须有数据支撑 |

## 三、今日活动提示（独立区块）

```markdown

```

## 四、结尾合规落款（每轮必带）

```markdown
——
据麦当劳 MCP 公开数据生成，营养/优惠以门店与活动页实际为准；本工具为第三方辅助，非官方推荐。
```
