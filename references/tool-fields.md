# 工具返回字段映射 · Tool Fields

> 本文件定义「麦麦健康省钱顾问」使用的 3 个麦当劳 MCP 工具的返回字段。
> **字段名以 `mcd-mcp` 实际返回为准**（下表为常见命名示例，解析时按「多别名容错」处理）。
> Skill 在 Step 2 取数后，按此表提取关键字段做分析。

---

## 1. list-nutrition-foods（餐品营养信息列表）

返回麦当劳常见餐品的营养成分。常见结构：

```json
{
  "foods": [
    {
      "name": "板烧鸡腿堡",
      "energy": 430,
      "protein": 28,
      "fat": 19,
      "carbohydrate": 34,
      "sodium": 980,
      "calcium": 120
    }
  ]
}
```

| 语义 | 常见字段名（容错别名） | 单位 | 用途 |
| --- | --- | --- | --- |
| 餐品名 | `name` / `foodName` / `item` | 文本 | 展示 |
| 能量 | `energy` / `calorie` / `kcal` | kcal | 热量筛选/累计 |
| 蛋白质 | `protein` | g | 蛋白密度排序 |
| 脂肪 | `fat` | g | 低脂肪筛选 |
| 碳水化合物 | `carbohydrate` / `carb` | g | 参考 |
| 钠 | `sodium` | mg | 低钠偏好 |
| 钙 | `calcium` | mg | 参考 |

> 解析容错：取能量时依次尝试 `energy`→`calorie`→`kcal`；取蛋白依次 `protein`。**若返回里没有单价字段，不要臆造价格**，仅在优惠匹配环节用券的优惠额表达「省多少」。

## 2. campaign-calendar（活动日历查询工具）

返回当月营销活动，含进行中 / 往期 / 未来。常见结构：

```json
{
  "campaigns": [
    {"name":"1024 程序员节 · M-Code 主题活动","status":"进行中","start":"2026-10-24","end":"2026-10-26","type":"节日主题"},
    {"name":"麦麦省 · 周一会员日","status":"进行中","start":"2026-10-01","end":"2026-10-31","type":"优惠"},
    {"name":"金拱门早餐卡返场","status":"未来","start":"2026-11-01","end":"2026-11-30","type":"会员"}
  ]
}
```

| 语义 | 常见字段名 | 用途 |
| --- | --- | --- |
| 活动名 | `name` | 展示 |
| 状态 | `status`（`进行中`/`往期`/`未来`） | **只把「进行中」当今日可叠加素材** |
| 开始 | `start` | 日期判断 |
| 结束 | `end` | 有效期 |
| 类型 | `type` | 分类提示 |

> 取数前务必调用 `now-time-info` 拿到「今天」，仅保留 `status === 进行中` 且 `start ≤ 今天 ≤ end` 的活动写进方案。

## 3. available-coupons（麦麦省券列表查询）

返回用户当前可领取的优惠券。常见结构：

```json
{
  "coupons": [
    {"name":"巨无霸套餐券","threshold":"满30","discount":"减12","validTo":"2026-10-31"},
    {"name":"麦辣鸡腿堡买一赠一","threshold":"无门槛","discount":"买1赠1","validTo":"2026-10-25"},
    {"name":"拿铁咖啡半价券","threshold":"满15","discount":"5折","validTo":"2026-10-31"}
  ]
}
```

| 语义 | 常见字段名 | 用途 |
| --- | --- | --- |
| 券名 | `name` | 展示 |
| 使用门槛 | `threshold`（如 `满30` / `无门槛`） | 判断组合是否满足 |
| 优惠 | `discount`（`减12` / `5折` / `买1赠1`） | 算省多少 |
| 有效期 | `validTo` | 提示过期 |

> 优惠额解析：识别 `减X`→ 直减 X 元；`X折`→ 按比例；`买N赠M`→ 视为省一份均价（需组合内有对应单品）。

## 取数纪律（再强调）

1. **先 `now-time-info` 再取数**，避免时间错位。
2. 一次只取必要字段，控制频率（≤600 次/分钟，防 429）。
3. 取数后向用户**展示关键原始数据摘要**，确认后再分析。
4. 任何工具未返回的字段，**不写、不编、不猜**；改用「以门店/活动页实际为准」。
